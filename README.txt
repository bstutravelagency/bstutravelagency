BSTU TRAVEL AGENCY WEBSITE
==========================

Files:
- index.html: complete responsive homepage
- assets/bstu-logo.jpeg: original supplied BSTU logo
- assets/app-icon-192.png and app-icon-512.png: app icons
- assets/apple-touch-icon.png, favicon.png, favicon-32.png: browser/mobile icons
- site.webmanifest: installable web-app icon metadata

How to use:
1. Extract this ZIP.
2. Upload the complete folder contents to your website hosting public_html folder.
3. Keep the assets folder next to index.html.
4. Open your domain to view the website.

The website uses Tailwind CSS via CDN and externally hosted destination photographs,
so an internet connection is required. External image URLs can change; a local logo
fallback is included for image loading errors. Review each external image provider's
licensing terms before using the website commercially.

LOGO UPDATE: Header and footer use the supplied BSTU navy-and-gold logo as a transparent PNG. Keep the assets folder beside index.html when uploading.
